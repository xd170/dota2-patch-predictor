# Dota 2 Patch Predictor

Автоматическая система мониторинга тестовых и публичных веток Dota 2 на базе **GitHub Actions** (Python 3.12) с расчетом откалиброванной краткосрочной вероятности выхода крупного патча и интерактивным Telegram-ботом.

## Возможности

- **Мониторинг двух источников**:
  - Источник Finargot (`versions.json` и `versions-history.json` с локальным 24-часовым кэшем `data/history_archive.json` и автоповторами при сбоях).
  - Прямой резервный опрос **Steam Web API** (`UpToDateCheck` + официальные новости `GetNewsForApp`) на случай временной недоступности Finargot.
- **Строгое разделение крупных и буквенных патчей**: в исторической базе моделируются только крупные номерные патчи (например, `7.41`, `7.42`), без смешивания с балансными буквами (`7.41b/c`).
- **Калиброванный прогноз без «выдуманных 99.9%»**:
  - Вероятности выхода на горизонтах **15 мин / 30 мин / 1 час / 2 часа / 3 часа**.
  - Индекс готовности (`0–100%`), оценка ближайшего окна по архиву (`01:08–03:52 Минск`, медиана `02:47`) и топ похожих прошлых патчей.
  - Проверено хронологическим backtesting'ом без заглядывания в будущее (Brier Score `0.00026–0.00065`).
- **Умные уведомления и защита от спама**:
  - Срочное оповещение при каждом новом билде `Staging`, скачке вероятности или обновлении `Public` / выходе новости в Steam.
  - Автоматическая блокировка повторных тревог после подтверждения релиза целевого патча.
  - **Вечерний пульс** 1 раз в сутки (`21:00–21:30` Минск), подтверждающий, что монитор активен.
- **Интерактивный Telegram-бот**:
  - Постоянные кнопки под строкой ввода и команды `/status`, `/builds`, `/history`, `/help`.

## Структура проекта

- `config.py` — целевой патч (`TARGET_PATCH`), часовой пояс (`Europe/Minsk`), URL источников и секреты.
- `collector.py` — загрузка Finargot с ретраями и кэшем `data/history_archive.json`.
- `steam_api.py` — прямая проверка Steam Web API (`UpToDateCheck` и `GetNewsForApp`).
- `features.py` — нормализация событий/патчей и причинный индекс `EventIndex` (без утечки будущего).
- `predictor.py` — расчет индекса готовности, откалиброванных вероятностей, ориентира окна и похожих патчей.
- `storage.py` — чтение/сохранение состояния (`data/state.json`) и истории наблюдений (`data/observations.jsonl`).
- `telegram_notifier.py` — рассылка, обработка команд/кнопок через `getUpdates` и форматирование сообщений.
- `monitor.py` — основной цикл мониторинга, детектора релиза и интерактивных ответов.
- `inspect_data.py`, `analyze_history.py`, `backtest.py` — утилиты разведки архива, статистики и backtesting'а.
- `.github/workflows/` — пайплайны GitHub Actions (`monitor.yml`, `backtest.yml`, `analyze.yml`, `inspect.yml`).

## Как пользоваться ботом в Telegram

В чате с ботом доступны постоянные кнопки или команды:
- **`📊 Статус патча`** (`/status`) — актуальные вероятности, готовность, возраст последних смен всех веток и факторы модели.
- **`🔧 Последние билды`** (`/builds`) — версии `client` / `server` по веткам `Staging`, `Public`, `Experimental` и последние 8 обновлений билдов.
- **`📈 Окно и патчи`** (`/history`) — сколько дней прошло с прошлого крупного патча, статистика окна Valve и похожие патчи.
- **`ℹ️ Справка`** (`/help`, `/start`) — показать кнопки меню и подсказку.

> Ответ на нажатие кнопки или команду приходит на ближайшем цикле запуска `monitor.py` (обычно каждые 1–5 минут).

## Как добавить друзей в рассылку

1. Попросите друга открыть вашего бота в Telegram и нажать **Start** (`/start`).
2. Узнайте его `chat_id` (например, через `@userinfobot` или `@RawDataBot`).
3. На GitHub откройте **Settings → Secrets and variables → Actions → `TELEGRAM_CHAT_IDS`** и укажите ID через запятую без пробелов:
   ```text
   123456789,987654321
   ```

## Что делать после выхода патча 7.42 (переключение на 7.43)

Когда целевой патч выйдет, бот отправит финальное уведомление со ссылкой на патчноут и поставит защиту от спама (`"target_patch_released": true`). Чтобы переключить монитор на следующий крупный патч:

1. В `config.py` измените строку `TARGET_PATCH` на новый патч (например, `"7.43"`).
2. В файле `data/state.json` сбросьте флаг:
   ```json
   "target_patch_released": false
   ```
   (и при необходимости обновите `"public_release_alerted_version": null`).
